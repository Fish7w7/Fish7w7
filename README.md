## Featured projects

### [Auri Desktop](https://github.com/Fish7w7/Auri)

A local-first Windows app for organizing manga, manhwa, webtoons, novels, and other serialized works. It keeps reading sources and chapter progress together in a library stored on your computer.

*TypeScript, React, Electron, SQLite*

### [Auri Extension](https://github.com/Fish7w7/Auri-Extension)

A Chromium extension that connects reading pages to the local Auri Desktop library. It matches the current page to works in the library and lets readers check and update chapter progress from the browser.

*TypeScript, React, Vite*

### [DiskSnoop](https://github.com/Fish7w7/DiskSnoop)

A Windows app that shows what takes up disk space and finds large files and duplicates. Users can review files and move them to a recoverable quarantine before deleting them.

*JavaScript, Electron*

### [Ludex](https://github.com/Fish7w7/Ludex)

Windows game launcher MVP that brings installed Steam and Epic Games titles into one library (TypeScript, React, Electron, Laravel, PostgreSQL).

### [Gatilho](https://github.com/Fish7w7/gatilho)

Paused MVP with a dashboard for managing price, percentage change, and volume alerts for stocks listed on Brazil's B3 exchange (Next.js, TypeScript, Python, FastAPI, PostgreSQL, Redis).

### [VoidMail](https://github.com/Fish7w7/VoidMail)

Local tool for finding high-volume senders in Gmail and reviewing messages before cleanup (Next.js, TypeScript, Python, FastAPI, Gmail API).

### [Log-Analyzer](https://github.com/Fish7w7/Log-Analyzer)

Command-line and web tool that flags suspicious patterns in HTTP access logs (Python, Flask).
